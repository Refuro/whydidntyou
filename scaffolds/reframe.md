## Discovery scaffold (generic; contains no information about any specific process)

Before each attempt, do all of the following explicitly, in writing, before the <code> block:
1. List every assumption your previous attempts shared. Pick one and drop it this time.
2. Name at least one quantity you have not yet measured on the sample. Measure it in your head or in code before deciding on an approach.
3. If the last two attempts were variations of the same idea, this attempt must be a different idea, not a refinement.
4. Define one new named object (a statistic, a structure, a transformed view of the data) and build the attempt around it.
